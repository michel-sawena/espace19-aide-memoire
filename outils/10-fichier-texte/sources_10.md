# Sources – Aide-mémoire n° 10 « Créer, enregistrer, fermer un fichier texte »

Vérifié le 27/11/2026 (séance parallèle, sujet imposé n° 10). Aide officielle d'abord, puis guides.

## Sources lues
1. **Microsoft – Aide de Bloc-notes Windows** (support.microsoft.com, fr-fr, page mise à jour le 04/10/2026) :
   https://support.microsoft.com/fr-fr/windows/aide-de-bloc-notes-windows-4d68c388-2ff2-0e7f-b706-35fb2ab88a8c
   Ouvrir : bouton « Démarrer », taper « Bloc-notes », sélectionner « Bloc-notes ». Menu « Fichier ». « Enregistrer sous ». Zone « Nom de fichier ».
2. **Microsoft Q&A – Comment enregistrer un document Bloc Note** (learn.microsoft.com, 2013, mise à jour 07/2025) :

   « Fichier » puis « Enregistrer » ou « Enregistrer sous » ; nom de fichier en .txt ; caractères interdits " / \ * ? < > | :
3. **Lenovo – Qu'est-ce qu'un bloc-notes ?** (lenovo.com/ch/fr, 05/11/2026) :
   https://www.lenovo.com/ch/fr/glossary/what-is-notepad/
   « Démarrer », taper « Bloc-notes » ; « Fichier » puis « Enregistrer » ; « Ctrl + S » ; bouton « Enregistrer » ; extension .txt automatique.
4. **Cursa – Comment utiliser le Bloc-notes dans Windows 11** (cours en ligne, non daté) :

## Libellés écrits tels quels (confirmés par au moins 2 sources)

- « Ctrl + S » (3, 5)
- « Nom de fichier » (1, 5) ; bouton « Enregistrer » de la fenêtre d'enregistrement (3, 5)
- extension « .txt » (2, 3)
- « Documents », « Explorateur de fichiers » : déjà vérifiés (sources_04.md)

## NON écrits (non confirmés ou variables selon la version)
- Le nom d'un document neuf (« Sans titre » ?) : l'onglet est dessiné sans nom avant l'enregistrement.
- La question posée à la fermeture et ses boutons : aucune source ne les décrit, et les versions récentes ne la posent plus toujours (source 6 ; la source 3 dit le contraire, elle est plus ancienne). La vidéo et la fiche disent seulement : « si une question s'affiche, choisissez d'enregistrer », et surtout « enregistrez toujours avant de fermer ».
- Le dossier proposé par défaut : on demande de cliquer sur « Documents » à gauche, sans supposer le dossier proposé.
- Le titre de la fenêtre d'enregistrement : dessiné sans titre.
