## Choix pédagogiques
- Ouvrir la session : « appuyez sur une touche ou cliquez » (Microsoft : une touche ; le clic de souris est le geste habituel sur un ordinateur de bureau, conseil de bon sens). Puis taper le code. Les points à la place des chiffres : constat de bon sens (le code reste caché).
- « Si rien ne se passe, appuyez sur Entrée » : conseil de bon sens (un code PIN ouvre souvent la session tout seul ; un mot de passe se valide avec Entrée). Le nom de la touche Entrée n'est pas un libellé d'écran.
- Nom affiché sur l'écran de connexion : prénom fictif « Marie ». Fond d'écran et icônes DESSINÉS, aucun logo ; le bouton Démarrer est figuré par quatre carreaux bleus, comme dans les sujets 02 et 08.
- La session (« porte de chez soi », code = clé) et le bureau (« table de travail ») : analogies des consignes.
- Pas de Ctrl+Alt+Suppr, pas de « Déconnexion » détaillée (trop pour ce public) ; seul « Windows + L » est donné en « Bon à savoir ».
