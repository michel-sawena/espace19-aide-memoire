## Décisions d'écriture
- Les trois boutons sont désignés par leur FORME (trait, carré, croix), comme dans Premiers Clics, avec le verbe de leur action (réduire, agrandir, fermer : confirmé par Guérande et Elephorm). Le nom exact de l'info-bulle n'est pas écrit comme libellé.
- Le contenu du menu du clic droit n'est PAS détaillé : les libellés changent selon l'endroit et la version de Windows 11 (« Afficher plus d'options » / « Afficher d'autres options » selon les sources). Le menu est dessiné avec des lignes grises, sans texte.
- « Glisser-déposer », « menu contextuel », « molette », « double flèche » : confirmés par au moins deux sources.
- Sens de la molette : vers soi, la page descend (OpenClassrooms : « faire descendre le contenu ») ; vers l'écran, elle remonte (RLV : « monter et descendre »).
