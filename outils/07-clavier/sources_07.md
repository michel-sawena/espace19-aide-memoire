# Sources – Aide-mémoire 07 « Découvrir le clavier »

Vérifiées le 27/11/2026. Plan de cours : « Découvrir le clavier : repérer les différentes parties du clavier » (Formation débutant, MAJ 09/2025).

## Sources lues
1. Microsoft, aide Windows, « Conseils et astuces sur le clavier Windows » (contenu daté du 23/03/2026, mis à jour le 04/11/2026) : support.microsoft.com/fr-fr/windows/windows-conseils-et-astuces-clavier-588e0b72-0fff-6d3f-aeee-6e5116097942. Noms : « touche Windows », « Maj », « Ctrl », « Alt », « pavé numérique ».
2. ANCT, Les Bases du numérique d'intérêt général, atelier « Découverte Ordinateur – Le clavier » (09/11/2022) : lesbases.anct.gouv.fr (PDF ATELIER-05). « Barre d'espace », « Entrée » (passer à la ligne, valider), « retour arrière » (supprime à gauche du curseur), « Suppr » (à droite), « Échap » (annule l'action en cours), « alt gr », pavé numérique « pas présent sur tous les ordinateurs ».
3. Ville de Beaucouzé, « Découvrir le clavier d'ordinateur » (PDF, déc. 2021) : beaucouze.fr. Zones (lettres AZERTY, caractères spéciaux, chiffres ; pavé numérique), « touche espace », « Entrée », « Echap (ESC) », « Maj », « Verr Maj », « Alt Gr » (à droite de l'espace), « Retour Arrière », « Suppr », touche Windows. Chiffres du haut avec Maj ; @ = Alt Gr + touche à ; portables souvent sans pavé numérique.
4. OpenClassrooms, « Faites vos premiers pas sur ordinateur – Manipulez la souris et le clavier » (non daté) : « Entrée », « Suppr. », « Shift » (flèche vers le haut), « VERR MAJ » (cadenas), « Alt Gr » ; « Pour écrire "1", il faut maintenir appuyée la touche "shift" puis la touche 1 ».

## Libellés écrits tels quels (confirmés par au moins 2 sources)
- Entrée (2, 3, 4) · Retour arrière (2, 3) · Suppr (2, 3, 4) · Échap (2, 3) · Maj (1, 2, 3 ; « Shift » en 4) · Verr Maj (3, 4) · Alt Gr (2, 3, 4) · barre d'espace (2 ; « touche espace » en 3) · touche Windows (1, 3) · pavé numérique (1, 2, 3).
- Chiffres de la rangée du haut = Maj + touche (2, 3, 4). Portables souvent sans pavé numérique (2, 3).
- Arobase = Alt Gr + touche « 0 à @ » (3 ; 4 dit « Alt Gr » sans la touche). Disposition AZERTY française standard : la touche 0 / à porte le @ ; décrit dans la vidéo comme « la touche du zéro ».

## Non écrits (une seule source ou source douteuse)
- « Verr Num » (seulement 3) : on dit « pavé de chiffres » sans nommer cette touche.
- Euro (Alt Gr + E seulement en 3 ; code Alt de la page Microsoft affiche un mauvais caractère).
