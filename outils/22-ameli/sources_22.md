# Sources – Aide-mémoire 22 « ameli.fr » (vérifiées le 27/11/2026)

## Sources officielles lues
1. ameli.fr – « Création de votre compte ameli et connexion : mode d'emploi »
   https://www.ameli.fr/assure/remboursements/suivre-remboursements/se-connecter-compte-ameli
   - Identifiant : numéro de sécurité sociale, **13 chiffres**, sans la clé à 2 chiffres ; puis le mot de passe.
   - Bouton de validation : **« Me connecter »** (confirmé).
   - **« Mot de passe oublié ? »** : numéro de sécurité sociale + date de naissance + adresse mail ; lien valable 30 minutes.
   - **« Créer un compte »** : il faut le RIB et la carte Vitale ; adresse mail à valider sous 7 jours.
   - Connexion possible aussi par **FranceConnect** (non montré, pour garder une seule méthode).
   - Application : « Compte ameli, l'Assurance Maladie ».
   - **36 46** : « service gratuit + coût de l'appel ».
2. ameli.fr – « Un code de sécurité demandé pour accéder à votre compte ameli »
   https://www.ameli.fr/assure/remboursements/suivre-remboursements/un-code-de-securite-demande-pour-acceder-votre-compte-ameli
   - Code à **6 chiffres**, envoyé à l'**adresse mail** du compte, valable **15 minutes**.
   - Code expiré : **« Recevoir un nouveau code de sécurité »** (confirmé). Mail non reçu : regarder les spams.
   - 3 échecs (mot de passe ou code) : compte bloqué **15 minutes**.
3. Assurance Maladie – communiqué « Tous vigilants face aux escroqueries » (2 juillet 2024)
   https://www.assurance-maladie.ameli.fr/presse/2024-07-02-cp-vigilance-escroqueries-assurance-maladie
   - Ne demande jamais : identifiants de connexion (mot de passe), informations médicales, coordonnées bancaires complètes ou numéro de carte bancaire.
4. Cybermalveillance.gouv.fr – « L'hameçonnage aux couleurs d'Ameli / Carte Vitale » (mise à jour 16/11/2026)
   https://www.cybermalveillance.gouv.fr/tous-nos-contenus/actualites/hameconnage-assurance-maladie-ameli
   - Ne jamais accéder au compte par un lien reçu par mail ou SMS ; passer par un favori ou l'application ; en cas de doute, contacter directement l'Assurance Maladie.
5. Forum officiel ameli – réponse certifiée par un expert (2 décembre 2022, page mise à jour le 30/07/2026)
   https://forum-assures.ameli.fr/questions/3070535-obtenir-attestation-droits
   - **« Attestation de droits »** depuis la page d'accueil du compte (rubrique « Vos démarches en 2 clics », ou « Vos documents »).

## Choix de présentation
- Écrans dessinés, simplifiés et neutres : aucun logo, aucune couleur ni charte de l'Assurance Maladie ; mention « (dessin simplifié) ».
- Numéro de sécurité sociale, code et attestation : exemples inventés, marqués « EXEMPLE ». Faux SMS : inventé, marqué « EXEMPLE de faux SMS ».
- Pas de page interactive (prévu « – » dans le plan : site officiel à ne pas imiter).
