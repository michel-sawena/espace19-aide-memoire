# Sources – 01 Créer un dossier personnel (vérifiées le 25/11/2026)

Sujet du plan : « Dossiers, fichiers et stockage › Créer un dossier personnel » (Formation débutant, MAJ 09/2025).

## Aide officielle (prioritaire)
- Microsoft Support, « Créer un dossier » (s'applique à Windows 10 et Windows 11), métadonnées ms.date 13/02/2026
  https://support.microsoft.com/fr-fr/Word/create-a-new-folder
  Étapes : ouvrir l'Explorateur de fichiers (touche Windows + E, icône, ou menu Démarrer) › aller à l'emplacement › sélectionner « Nouveau », puis « Dossier » › taper le nom › Entrée.
  Remarque de la page : le nom ne doit pas contenir de barres obliques, deux-points, points-virgules, tirets ni points.
- Microsoft Support, « Explorateur de fichiers dans Windows » : l'Accès rapide est renommé « Accueil » depuis Windows 11 22H2.

## Guides datés (recoupement)
- info.fr, « Comment créer un dossier sur ordinateur », 27/12/2025 : clic droit dans l'espace souhaité › nouveau dossier ; raccourci Ctrl + Maj + N.
- tecnoloblog.com, guide Explorateur de fichiers Windows 11, 2026 : clic droit sur un espace vide › « Nouveau » › « Dossier », donner un nom.
- cursa.app, « Comment utiliser l'Explorateur de fichiers dans Windows 11 » : clic droit › « Nouveau » › « Dossier ».

## Libellés écrits tels quels (confirmés)
- « Explorateur de fichiers », « Documents », « Nouveau », « Dossier », touche « Entrée », nom par défaut « Nouveau dossier ».

## Choix pédagogiques
- Méthode 1 (officielle) : bouton « Nouveau » de la barre de commandes, puis « Dossier ».
- Méthode 2 (guides) : clic droit dans un espace vide › « Nouveau » › « Dossier ».
- Noms d'exemple sans tiret ni point : « Famille » (démonstration), « Recettes » (exercice).
- Écrans dessinés (simulation simplifiée de Windows 11), pas de capture réelle.
