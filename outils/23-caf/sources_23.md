# Sources – Aide-mémoire 23 « La CAF en ligne »

Vérifiées le 27/11/2026. Plan : « Formation débutant - complément démarches en ligne » → La CAF en ligne (caf.fr) : se connecter, faire une démarche simple.
Démarche simple choisie : télécharger une attestation (la plus courante, sans risque, sans rien modifier au dossier).

## Aide officielle (CAF)
1. caf.fr, « La connexion à Mon Compte » (sans date visible) – https://www.caf.fr/allocataires/actualites/la-caf-et-vous/la-connexion-mon-compte
   - Identifiant : les 13 premiers chiffres du numéro de sécurité sociale ; mot de passe Caf de 8 à 24 caractères (chiffres et lettres) ; lien « Mon Compte » dans le menu ; « Déconnexion » dans le menu ; 3230 (service gratuit + prix d'un appel).
   - Mot de passe oublié : vérification de l'état civil, puis code à 6 chiffres par mail ou SMS au choix.
2. Fiche CAF « Me connecter à Mon Compte » (MAJ 02/2024) – https://www.caf.fr/sites/default/files/medias/cnaf/Aides_et_demarches/Mes-demarches/Fiches-pratiques/Me-Connecter-a-Mon-Compte.pdf
   - « Mon Compte » dans la barre de menu ; bouton « Se connecter » ; lien « Mot de passe oublié ? » ; bouton « S'identifier avec FranceConnect » (choix impots.gouv.fr, ameli.fr, La Poste, MSA…) ; bouton « Déconnexion ».
3. Actualité CAF « Double authentification : l'accès à votre espace Mon Compte mieux protégé » (09/01/2025) – https://www.caf.fr/allocataires/actualites/actualites-nationales/double-authentification-l-acces-votre-espace-mon-compte-mieux-protege
   - Après « Se connecter » : bouton « Envoyer le code » ; code à 6 chiffres envoyé par mail, valable 15 minutes ; nouveau code possible ; « En aucun cas, un conseiller de la Caf ne vous demandera ce code. »
4. Fiche CAF « Télécharger une attestation dans Mon Compte » (MAJ 11/2024) – https://caf.fr/sites/default/files/medias/cnaf/Aides_et_demarches/Mes-demarches/Fiches-pratiques/Telecharger-une-attestation-dans-Mon-Compte.pdf
   - Rubrique « Mes attestations » ; attestation de paiement ou de quotient familial ; choix de la période ; téléchargement.
5. CAF du Var, « Télécharger une attestation » – https://caf.fr/allocataires/caf-du-var/offre-de-service/thematique-libre/telecharger-une-attestation
   - « Mes attestations » → type → « mois précédent » ou « une autre période » → bouton « Télécharger » ou « Recevoir par courrier » ; autres rubriques « Mes démarches », « Mon profil ».

## Non écrits (non confirmés)
- Le libellé du bouton qui valide le code : la vidéo dit « validez » et le dessin montre une simple flèche.
- Le libellé des cases de connexion : les dessins portent des légendes descriptives (« numéro de sécurité sociale (13 chiffres) », « mot de passe »), pas le texte exact du site.

## Choix de présentation
- Écrans simplifiés et neutres : aucun logo, aucune couleur ni charte du site officiel ; mention « (dessin simplifié) ».
- Chiffres inventés et marqués « EXEMPLE » (numéro de sécurité sociale, code 482 913, attestation).
- Pas de page interactive (plan : « – », on n'imite pas l'écran de connexion d'un site officiel).
- Le site peut changer : en cas de différence, la fiche renvoie vers le 3230 ou Espace 19.
