La CAF en ligne.

La CAF verse des aides, comme l'aide au logement. Sur son site, caf point f r, vous suivez votre dossier chez vous. Prenez votre temps.

D'abord, préparez trois choses. Votre carte Vitale. Votre mot de passe de la CAF. Et votre boîte mail, pour recevoir un code.

Ouvrez le navigateur. Dans la barre d'adresse, tapez caf point f r, puis appuyez sur Entrée.

Sur la page d'accueil, cliquez sur Mon Compte.

Dans la première case, tapez les treize premiers chiffres de votre numéro de sécurité sociale. Il est écrit sur votre carte Vitale.

Dans la deuxième case, tapez votre mot de passe de la CAF. Puis cliquez sur Se connecter.

Pour votre sécurité, cliquez sur Envoyer le code. Ouvrez votre boîte mail : un code à six chiffres vous attend. Tapez ce code, puis validez.

Attention, ce code est secret. Un conseiller de la CAF ne vous le demandera jamais.

Vous voici dans votre espace personnel. Bravo !

Mettez la vidéo en pause, et essayez sur votre ordinateur.

Faisons une démarche simple : télécharger une attestation. C'est un papier officiel qui prouve vos aides. Cliquez sur Mes attestations.

Choisissez l'attestation de paiement. Puis choisissez la période, par exemple le mois précédent.

Cliquez sur Télécharger. L'attestation s'ouvre : vous pouvez l'enregistrer ou l'imprimer.

Quand vous avez fini, cliquez sur Déconnexion. C'est comme fermer la porte à clé en partant.

Mot de passe oublié ? Cliquez sur le lien Mot de passe oublié. Vous pouvez aussi appeler la CAF au trente-deux trente, ou venir à Espace 19.

À vous de jouer ! Connectez-vous, puis téléchargez une attestation. Mettez la vidéo en pause.

Voici la solution. caf point f r, puis Mon Compte. Numéro de sécurité sociale, mot de passe, Se connecter, puis le code. Ensuite, Mes attestations, le type, la période, et Télécharger.

Retenez bien : Mon Compte, la carte Vitale, le mot de passe, le code par mail. Et Déconnexion à la fin. À bientôt à Espace 19 !
