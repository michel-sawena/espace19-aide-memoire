# Sources – 05 La souris : le curseur et les clics (vérifiées le 27/11/2026)

Sujet du plan : « Formation débutant.docx », partie Souris : curseur, clics, lancer et quitter un programme.
Le clic droit, le déplacement, l'agrandissement et la molette sont réservés au sujet 06.

## Aide officielle
- Microsoft, « Modifier les paramètres de la souris » (ms.date 31/03/2026, mise à jour 04/11/2026).
  https://support.microsoft.com/fr-FR/Windows/Hardware/Input-Devices/change-mouse-settings
  Bouton principal « Gauche » ou « Droite » (le bouton gauche est le bouton principal par défaut) ; réglage « Vitesse du double-clic » (le double-clic doit être assez rapide). La page ne décrit pas les gestes eux-mêmes : ils sont recoupés ci-dessous.

## Guides (recoupement)
- OpenClassrooms, « Manipulez la souris et le clavier » (cours « Faites vos premiers pas sur ordinateur », non daté) :
  « Déplacer le curseur sur l'écran en déplaçant la souris » ; le clic gauche « permet de sélectionner un élément » ; le double-clic « permet d'ouvrir des logiciels ou éléments » ; pour fermer, « faire un clic gauche sur la croix en haut à droite ».
  https://openclassrooms.com/fr/courses/5737801-faites-vos-premiers-pas-sur-ordinateur/5890463-manipulez-la-souris-et-le-clavier
- Lenovo, glossaire « Qu'est-ce qu'un double clic ? » (métadonnée 05/11/2026) : « appuyez rapidement sur le bouton gauche de votre souris deux fois de suite » ; sous Windows, « le double clic est activé par défaut pour ouvrir des programmes et des documents ».
  https://www.lenovo.com/ch/fr/glossary/double-click/
- Premiers Clics (Thibaut Mathieu), « Windows facile – Maîtriser Windows 11 » (PDF, © 2022) : « A l'écran, la souris est représentée par le curseur, encore appelé le pointeur » ; « Le double clic s'effectue toujours avec le bouton gauche » ; il « permet d'ouvrir un fichier ou un dossier, et de lancer un logiciel » ; lancer un programme : « effectuez un double-clic sur l'icône ».
  https://www.premiers-clics.fr/download/pdf/Premiers-Clics-Windows-facile-windows-11.pdf
- Médiathèques RLV, fiche « Utiliser la souris » (PDF, non daté) : double-clic : « Appuyer deux fois rapidement, sans bouger la souris, pour ouvrir un dossier ou un fichier » ; « La flèche indique la position de la souris sur l'écran ».
  https://atelier-mediatheque.rlv.eu/blog/ressources-de-formation-au-numerique/Utiliser_la_souris.pdf
- Médiathèques RLV, fiche « Les fenêtres » (PDF, non daté) : bouton de fermeture : « Fermer complètement la fenêtre ».
  https://atelier-mediatheque.rlv.eu/blog/ressources-de-formation-au-numerique/Les_Fenetres.pdf
- Bloc-notes (nom du programme de Windows 11) : Cursa, « Comment utiliser le Bloc-notes dans Windows 11 » ; IT-Connect et Le Monde Informatique (articles sur le Bloc-notes de Windows 11).
  https://cursa.app/fr/page/comment-utiliser-le-bloc-notes-dans-windows-11

## Libellés écrits tels quels
- « curseur » (et « pointeur ») : Premiers Clics + OpenClassrooms + RLV.
- « clic » (bouton gauche, choisir/sélectionner) : OpenClassrooms + Premiers Clics + RLV.
- « double-clic » (deux fois vite, sans bouger, pour ouvrir) : Lenovo + Premiers Clics + RLV + OpenClassrooms.
- « la croix en haut à droite » pour fermer : OpenClassrooms + RLV (« Fermer ») + Premiers Clics. Le mot « Fermer » n'est écrit qu'en info-bulle de la page d'entraînement ; la vidéo et la fiche disent « la croix ».
- « Bloc-notes » : Cursa + IT-Connect + Le Monde Informatique.
- « Corbeille » : repris du sujet 03 (sources_03.md).
- « Photos » : nom de dossier fictif (exemple), pas un libellé de Windows.

## Choix pédagogiques (bon sens, non tirés d'un libellé)
- Tenir la souris : index sur le bouton gauche, majeur sur le bouton droit, sans serrer. Aucune des sources lues ne le décrit ; c'est la tenue enseignée en salle.
- Au bord de la table : soulever la souris et la reposer (le curseur ne bouge pas en l'air). Conseil de bon sens, non tiré d'une source.
- L'icône choisie « se colore en bleu » : constat visuel sous Windows 11 (surbrillance bleue), dessiné dans la vidéo.
- « Si un petit cercle tourne, l'ordinateur travaille : patientez » : pointeur d'attente de Windows ; aucun libellé n'est écrit.
- Démonstration avec le dossier « Photos » (comme dans le sujet 03) et le Bloc-notes (programme présent dans Windows 11). Écrans DESSINÉS, aucun logo.
- Contrôle de l'assemblage : la phrase « Pas de panique ! » (4 syllabes, rapport 0,65) a été vérifiée à la main : ses deux limites tombent dans des silences de la voix (parole entre 113,2 s et 114,2 s). Elle est acceptée par `assemble_05.py`, une copie de `assemble_v2.py` qui accepte seulement une phrase de moins de 6 syllabes dont les deux limites tombent dans un silence.
