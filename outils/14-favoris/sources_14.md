# Sources – 14 Ajouter et retrouver ses favoris (vérifiées le 27/11/2026)

Sujet du plan : « Formation débutant.docx » (MAJ 09/2025), partie « Introduction à Internet » : « Ajouter des pages aux favoris et les afficher ».

## Aide officielle (prioritaire)
- Microsoft, « Add sites to your favorites in Microsoft Edge » (page mise à jour le 28/10/2026) : ajouter la page avec le bouton « Add this page to favorites » situé dans la barre d'adresse ; renommer le favori ou choisir un autre dossier, puis valider (« Done ») ; autre chemin : « Settings and more » > « Favorites » ; les favoris se retrouvent dans le menu des favoris ou la barre des favoris.
  https://support.microsoft.com/help/4027306
- Google, « Raccourcis clavier dans Chrome » : « Enregistrer la page active dans les favoris | Ctrl+d » ; « Afficher ou masquer la barre de favoris | Ctrl+Maj+B » ; « Ouvrir le gestionnaire de favoris | Ctrl+Maj+O ».
  https://support.google.com/chrome/answer/157179?hl=fr

## Guides datés (recoupement)
- Premiers Clics, « Ajouter un site aux favoris » (mis à jour le 05/11/2026) : « cliquez sur l'icône étoile à droite de la barre d'adresse » ; une fenêtre s'ouvre pour le nom et le dossier ; Ctrl+D ouvre directement cette fenêtre ; l'étoile colorée indique que la page est déjà enregistrée ; menu (trois points) > « Favoris et listes ».
  https://www.premiers-clics.fr/en/windows-basics/add-website-to-favorites-shortcut/
- Clubic, « Comment ajouter un site aux favoris sur Google Chrome » (22/05/2021) : « étoile » à droite de la barre d'adresse ; « Une fenêtre s'affiche alors, vous pouvez changer le nom du favori et définir le dossier ».
  https://www.clubic.com/tutoriels/article-885897-1-comment-ajouter-site-favoris-google-chrome.html
- Clubic, « Raccourcis clavier indispensables sur Edge » (24/05/2021) : « Ctrl + D : Enregistrer votre page web actuelle en tant que favori » ; « Ctrl + Maj + B : Afficher ou masquer la barre des favoris » ; « Ctrl + Maj + O : Ouvrir la Gestion des favoris ».
  https://www.clubic.com/navigateur-web/microsoft-edge/tutoriel-893237-1-raccourcis-clavier-indispensables-edge.html

## Libellés et faits écrits tels quels
- « favoris », « barre d'adresse » : Microsoft + Google + Clubic + Premiers Clics.
- Bouton en forme d'étoile au bout (à droite) de la barre d'adresse : Microsoft (bouton dans la barre d'adresse) + Premiers Clics + Clubic (étoile).
- Petite fenêtre avec le nom et le dossier : Microsoft + Clubic + Premiers Clics.
- Menu des trois petits points en haut à droite, puis « Favoris » : Microsoft (« Settings and more » > « Favorites ») + Premiers Clics (trois points > « Favoris et listes »). On écrit seulement « Favoris », commun à Edge et Chrome.
- Ctrl + D : Google + Clubic + Premiers Clics. Ctrl + Maj + B (barre des favoris) : Google + Clubic.
- NON écrits : le texte exact du bouton de validation (« Done » confirmé en anglais seulement ; « Terminé » / « OK » / « Confirmer » varient selon les sources) : on dit « le bouton bleu » et on dessine une coche ; le titre de la petite fenêtre ; l'infobulle exacte de l'étoile ; la couleur exacte de l'étoile une fois remplie (on dit « elle se remplit »).

## Choix pédagogiques
- Analogie : un favori, c'est un marque-page glissé dans un livre ; on retrouve la page sans chercher.
- Navigateur montré : Microsoft Edge (déjà installé sur Windows, comme au sujet 12), dessiné de façon simplifiée, sans logo. Les gestes sont les mêmes dans Chrome (étoile, trois points, Favoris).
- Exemple de site : google.fr, page dessinée simplifiée et neutre (comme au sujet 12).
- Page interactive prévue (plan : ⬜) : ajouter la page aux favoris, puis la retrouver.
