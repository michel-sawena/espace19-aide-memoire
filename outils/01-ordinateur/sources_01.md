# Sources – 01 Découvrir l'ordinateur : fixe et portable (vérifiées le 25/11/2026)

Sujet du plan : « Formation débutant - complément prise en main.docx » (ajout du 25/11/2026), point 1 : reconnaître un ordinateur fixe (unité centrale ou tout-en-un, écran, clavier, souris) et un portable (écran, clavier et pavé tactile réunis) ; noms des principaux composants et périphériques ; où se branchent l'alimentation et les câbles principaux. Complète « Présentation d'un ordinateur » du plan officiel (MAJ 09/2025).

## Source officielle (prioritaire)
- ANCT – Les Bases du numérique d'intérêt général (site de l'État pour la médiation numérique), « Découvrir les bases de l'ordinateur (partie 1) », MAJ 06/07/2022.
  https://storage.lesbases.anct.gouv.fr/main/user/2e026782-498e-4fac-a766-d5eeed3d8417/sCUoKTTFgAwZjQvLYpPQ9_Decouvrir-les-bases-de-lordinateur-partie-1.pdf
  Fixe : « Unité centrale séparée de l'écran » ; portable : « Unité centrale intégrée avec l'écran », « le pavé tactile (touchpad) remplace la souris ». Périphérique : matériel qui fonctionne avec l'ordinateur sans en être une partie essentielle (clavier, souris, enceintes). Connectiques : HDMI, VGA, USB type A, USB type C, Ethernet (RJ45), jack. Le bloc d'alimentation, dans l'unité centrale, convertit le courant de la prise murale.
- Lenovo (fabricant), « Un guide pour comprendre les ports des ordinateurs de bureau » (pas de date affichée, page consultée le 25/11/2026).
  https://www.lenovo.com/ch/fr/glossary/desktop-computer-ports
  Ports USB, HDMI, Ethernet (« port réseau »), VGA (« ancien type de connexion ») ; port audio souvent vert (casque, haut-parleurs), micro souvent rose. Certains portables se rechargent par USB Type-C, d'autres par leur adaptateur d'alimentation.
- Aucune page support.microsoft.com ne traite ce sujet matériel de façon générale (les pages trouvées concernent les seuls appareils Surface) : l'aide d'un fabricant et la ressource de l'État ont donc servi de référence.

## Choix pédagogiques
- Pas de clic Windows dans ce sujet : pas de page interactive (prévu « – » dans le plan).
- Ports présentés : seulement alimentation, écran (HDMI), USB, et casque (jack) en mention. Ethernet, VGA, DisplayPort volontairement omis (trop de détail pour ce public).
- Conseil de prudence (pédagogique, non tiré d'une source) : ne jamais forcer une fiche ; débrancher l'alimentation seulement ordinateur éteint.
- « La prise USB classique ne rentre que dans un sens » : vrai pour l'USB type A (forme rectangulaire, détrompeur) ; l'USB-C se branche dans les deux sens (mentionné seulement pour le chargeur).
- Écrans et appareils DESSINÉS, sans marque ni logo.
